# The Great Notch Inn — v7 saved website

This version preserves the existing dark red roadhouse design and the Inn's real photographs. Version numbers are kept in the folder name, outside the public website title.

Double-click **Start Preview.command** to open this saved version in your browser. Keep its window open while viewing. The local web address is needed for reliable YouTube playback; opening index.html directly is useful for a quick visual check but does not supply the web referrer required by YouTube.

Changes in this working version:
- About four seconds of loading, a horizontal progress bar, skip button, and independent recovery deadline.
- Transparent logo PNG and uppercase loading-screen copy.
- ALL-CAPS section subtitles and justified reading paragraphs.
- Compact phone layout with collapsible sections, five upcoming shows at a time, and small batches of photos, videos, articles, bands and merchandise. Menu and footer links open the requested section; desktop keeps every section open. Closing Videos on a phone stops hidden audio.
- All-day events excluded from upcoming, past, cached and monthly calendar views. The monthly view reads timed shows from the same live Google Calendar and has previous/next/Today controls.
- Hours, music nights, bar pies, cash/ATM, and 21+ policy filled from confirmed project records.
- Eight videos, including the requested Liquid Death video. Direct YouTube links are available below every player.
- Relative image paths for hosting within a folder, repaired old band destinations, and removed obsolete press links.
- Calendar dates and times use New Jersey's Eastern time. Keyboard/focus handling and form validation are improved.

The contact form opens the visitor's email app; it is not a mail delivery service. Updating the public Google Calendar updates the on-page schedule.

See QA.md for completed verification and external-site restrictions. The original files remain in v4, and intermediate saved revisions remain in v5 and v6. Future requests should start a fresh numbered version unless the user explicitly asks to update an existing version. This refinement was explicitly requested in v7.
